### 📦 Projeto em destaque

#### [Almoxarifado CECAPE](https://github.com/ermelsu/almoxarifado-cecape)
Sistema web completo de **gestão de almoxarifado e requisição de materiais**, **em produção
na AWS** e usado diariamente por dezenas de colaboradores da faculdade.

- Ciclo completo: **requisições → estoque → notas fiscais → relatórios**, com
  multi-almoxarifado, importação de **NF-e (XML)**, custo médio ponderado e relatórios
  contábeis ao vivo.
- **~15.000 linhas** · **97 endpoints** · **23 modelos de dados** · **30 migrações**.
- Deploy **sem downtime** (Elastic Beanstalk *Immutable* + CloudFront) e **CI/CD** com
  GitHub Actions.

`React` · `Node.js` · `Express` · `Prisma` · `PostgreSQL` · `AWS`
